# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Supabase Setup (Required before running)

1. Create a free project at https://supabase.com
2. Run `supabase/migrations/001_initial.sql` in the Supabase SQL Editor
3. Copy `.env.example` to `.env` and fill in your project URL and anon key:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJ...
   ```
4. In Supabase dashboard → Authentication → Providers, enable **Google** and/or **Email**
5. For Google OAuth, add `https://your-vercel-url.vercel.app` to allowed redirect URLs
6. For Vercel deploy: add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` as environment variables in the Vercel project settings

## Commands

```bash
npm run dev        # dev server (also activates MCP file sync at /api/sync)
npm run build      # tsc -b && vite build  (type-check + bundle)
npm run lint       # oxlint (NOT eslint)
npm run preview    # preview production build

# MCP server (separate package)
cd mcp-server && npm install && npm run build   # first time
node mcp-server/dist/index.js                   # run the MCP server
```

No test runner is configured — there are no tests.

## Critical TypeScript Rules

**`verbatimModuleSyntax` is enabled** — all type-only imports MUST use `import type`:
```ts
import type { Transaction, Category } from './types';   // ✅
import { Transaction } from './types';                   // ❌ build error
```
`noUnusedLocals` and `noUnusedParameters` are errors — remove unused imports immediately.

## State / Data Flow

All app state lives in a single `AppData` object (`src/context.tsx`) backed by `localStorage` key `"expense-tracker-data"`.

- **Never write to localStorage directly** — mutations go through pure functions in `src/store.ts`.
- `saveData()` also calls `syncToFile()` which fires a best-effort `POST /api/sync` (only active in dev via Vite plugin in `vite.config.ts`).
- Pages/components consume state exclusively via `useApp()` from `src/context.tsx`.

## MCP Server

The MCP server lives in `mcp-server/` — a completely separate Node.js package with its own `package.json` and `tsconfig.json`.

- Data source: `~/.expense-tracker/data.json` (written by Vite dev plugin when running locally)
- Uses `@modelcontextprotocol/sdk` v1.x — `server.tool()` (deprecated but simpler API used to work around TS2589 depth-limit bug with `registerTool` generics)
- `// @ts-nocheck` at top of `mcp-server/src/index.ts` is intentional — MCP SDK Zod generics hit TypeScript's instantiation depth limit
- Build step prepends `#!/usr/bin/env node` to `dist/index.js` via inline Node script in `package.json` scripts
- Excel export in MCP uses `exceljs` (async `wb.xlsx.writeFile()`)
- Claude Desktop config: `~/Library/Application Support/Claude/claude_desktop_config.json`
- See `mcp-server/README.md` for full setup instructions and config examples

## Excel Export (Web App)

- `src/utils/exportExcel.ts` — pure async function `exportToExcel(data: AppData)`, generates 4-sheet `.xlsx` using `exceljs` and triggers browser download
- Uses `wb.xlsx.writeBuffer()` then `URL.createObjectURL()` for browser download
- Currency format string: `"$"#,##0.00`, date format: `DD-MMM-YYYY`
- Button is on the Reports page (`src/pages/Reports.tsx`) top-right

## PWA / iOS

- `public/manifest.json` — PWA manifest with `display: standalone`, `theme_color: #2563eb`
- `public/sw.js` — cache-first service worker, caches app shell + assets
- Registered in `src/main.tsx` on window `load` event (best-effort, non-fatal)
- `src/components/InstallBanner.tsx` — shows iOS "Add to Home Screen" prompt; detects iOS Safari + not standalone mode; dismissed state stored in `sessionStorage`
- Icons at `public/icons/icon-180.png`, `icon-192.png`, `icon-512.png` (generated by `node scripts/gen-icons.mjs`, requires `canvas` package)
- `viewport-fit=cover` in `index.html` — required for `env(safe-area-inset-*)` to work on iPhone notch/home-bar
- `h-[100dvh]` used in Layout (not `h-screen`) — avoids iOS Safari address bar jump bug

## Date / Budget Conventions

- `Transaction.date` is always `YYYY-MM-DD` (string). Always append `T00:00:00` when constructing `Date`: `new Date(tx.date + 'T00:00:00')`
- `Budget.month` is always `YYYY-MM`.

## Recharts Tooltip Formatter

Cast to `any` to avoid `NameType` mismatch:
```tsx
formatter={((v: unknown, name: unknown) => [...]) as any}
```
